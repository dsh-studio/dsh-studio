# 供应商渠道返佣政策调研(2026-08-20)

结论先行:**头部平台没有公开的现金返佣,给的都是平台代金券/credits**。
阶段①「返佣收入」要修正为「credits 补贴闭环」,现金收入的现实路径在阶段②差价和
远期渠道商协议。

## 各家实况

| 平台 | 机制 | 形态 | 对我们的用法 |
|---|---|---|---|
| 硅基流动 | 「推荐官」计划(至 2026-12-31):邀请注册+实名,双方各得 ¥16 通用代金券,不限人数 | 代金券,不可提现,禁倒卖 | **主推**。用户领 ¥16 白嫖额度(获客卖点),我们账户攒的券喂给阶段②体验额度池 |
| OpenRouter | Referral:被邀请人消费满 $10,双方各得 $5 credits;无公开现金 affiliate | credits,不可提现 | 海外模型场景的次推位 |
| DeepSeek 官方 | 无公开分销/返佣;且 2026-08 起 API 涨价(v4-pro 优惠结束调价,"低价红利落幕") | — | 默认直连位(信任),不指望它产生收入;涨价反而抬升"帮用户找便宜接入"的价值 |
| 火山方舟 / 阿里百炼 | 无公开个人返佣;渠道商体系走线下商务,要公司主体+流水承诺 | 线下协议 | 远期,量级起来再谈 |
| LLM Gateway 等小聚合 | 有 1% referred spend 现金分成一类的激进政策 | 现金 | 可靠性/合规弱,不做默认推荐 |

## 对产品的三个修正

1. **阶段①的本质是获客飞轮不是收入**:预设里放硅基流动推荐位(带我们邀请链接),
   用户注册领 ¥16 → 我们攒等额 credits → 反哺"新用户体验额度"(阶段②燃料),
   把体验成本打到近零。宣传口径是"注册就送 2000 万 tokens",这是真实卖点。
2. **现金收入的第一个现实节点是阶段②充值差价/轻中转**,不是阶段①。
   排期不用提前,但心理预期要对。
3. **预设插件的接入策略**:baseURL 全部用官方端点(不做流量中转,零合规风险),
   邀请绑定只发生在"注册引导链接"层,和 API 流量解耦。
