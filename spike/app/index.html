还没有 API Key? 查看免费领取教程(新用户 0 元起用)

  1. 注册并实名(手机号即可)。打开注册页 ↗
    新用户送 2000 万 tokens(约14元),实名后礼包页可再领代金券,够跑数百次任务
  2. 建密钥:控制台「API 密钥」→ 新建 → 复制。打开密钥页 ↗
  3. 回来粘贴:接口地址我已为你填好;模型 ID 去「模型广场」挑一个复制过来。打开模型广场 ↗
  1. 注册 DeepSeek 开放平台(手机号)。打开注册页 ↗
  2. 建密钥:「API keys」→ 创建 → 复制。打开密钥页 ↗
  3. 回来粘贴:接入方式已切为「DeepSeek 官方」,粘贴 Key 保存即可(默认模型 v4-flash,充几元可长期用)。

密钥只写入本机应用数据目录,不会上传到任何服务器。
